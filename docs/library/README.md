# World Building Library

A collection to browse, question, and turn into small experiments. Entries were curated with AI assistance; inclusion does not mean I have read or tried them.

- [Inspiration Gallery](Inspiration%20Gallery.md) — six visual directions and small experiments.
- [Inspiration Board](Inspiration%20Board.canvas) — spatial cards in Obsidian; double-click a source card to explore its website. External previews depend on the source website and connection.
- [Reference Library](Reference%20Library.md) — a reading order for the current sandbox.
- [Resource Capture Template](Resource%20Capture%20Template.md) — duplicate this when recording a new find.

## Start here

1. Pick **Terrain & biomes** in the gallery.
2. Read the noise resource in the reference library.
3. Try only one change in the existing `app/` sandbox.
4. Capture the result in a tutorial, including the prompt and what changed.
5. Add a backlog item only if the experiment is worth implementing.

The board contains source links, not screenshots of completed experiments. Add your own captures and observations as you explore. Notes and images in this library are stored in the course repository.
